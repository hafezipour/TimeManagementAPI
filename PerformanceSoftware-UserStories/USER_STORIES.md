# Performance Review Software - User Stories
## Based on Performyard Structure

---

## 1. REVIEW CYCLES

### 1.1 Review Cycle Creation and Management

**US-001: Create Review Cycle**
- **As an** administrator
- **I want to** create a new review cycle with a name, description, start date, end date, and review period
- **So that** I can organize and schedule performance reviews for specific time periods

**US-002: Assign Review Templates to Cycle**
- **As an** administrator
- **I want to** assign one or more review templates to a review cycle
- **So that** all participants in the cycle use consistent evaluation criteria

**US-003: Assign Employees to Review Cycle**
- **As an** administrator
- **I want to** assign individual employees, teams, or departments to a review cycle
- **So that** the appropriate people are included in the evaluation process

**US-004: Set Review Cycle Dates**
- **As an** administrator
- **I want to** set start date, end date, and deadline dates for a review cycle
- **So that** participants know when reviews begin, when they're due, and when the cycle closes

**US-005: Configure Review Cycle Settings**
- **As an** administrator
- **I want to** configure settings such as auto-reminders, visibility rules, and approval workflows for a review cycle
- **So that** the review process runs smoothly and according to organizational policies

**US-006: Lock Review Cycle**
- **As an** administrator
- **I want to** lock a review cycle from non-administrator access
- **So that** I can maintain control over the review process and prevent unauthorized changes

**US-007: Clone Review Cycle**
- **As an** administrator
- **I want to** clone an existing review cycle with all its settings and templates
- **So that** I can quickly create similar cycles for different time periods or groups

**US-008: Archive Review Cycle**
- **As an** administrator
- **I want to** archive completed review cycles
- **So that** I can maintain a historical record while keeping active cycles organized

### 1.2 Review Cycle Monitoring and Progress

**US-009: View Review Cycle Progress**
- **As an** administrator
- **I want to** view real-time progress of a review cycle showing completion status, pending reviews, and overdue items
- **So that** I can monitor the review process and ensure timely completion

**US-010: Track Review Completion Rates**
- **As an** administrator
- **I want to** see completion rates for each review type (self-review, peer review, manager review, etc.) within a cycle
- **So that** I can identify bottlenecks and take corrective action

**US-011: Send Reminders for Pending Reviews**
- **As an** administrator
- **I want to** send automated or manual reminders to reviewers who have pending reviews
- **So that** I can ensure all reviews are completed on time

**US-012: View Review Cycle Dashboard**
- **As an** administrator
- **I want to** view a dashboard showing key metrics for a review cycle (completion percentage, average ratings, response rates)
- **So that** I can quickly assess the health and progress of the review cycle

**US-013: Close Review Cycle**
- **As an** administrator
- **I want to** close a review cycle when all reviews are complete
- **So that** I can finalize the evaluation period and prevent further changes

**US-014: Reopen Closed Review Cycle**
- **As an** administrator
- **I want to** reopen a closed review cycle for corrections or additions
- **So that** I can handle exceptional cases where changes are needed after closure

### 1.3 Review Cycle Templates

**US-015: Create Review Cycle Template**
- **As an** administrator
- **I want to** create reusable review cycle templates with predefined settings
- **So that** I can quickly set up new cycles with consistent configurations

**US-016: Apply Template to Review Cycle**
- **As an** administrator
- **I want to** apply a template when creating a new review cycle
- **So that** I can standardize review processes across different cycles

## 5. WEIGHTAGES OF REVIEW FORMS

### 5.1 Form-Level Weightages

**US-099: Set Review Form Weight**
- **As an** administrator
- **I want to** assign a weight percentage to each review form type in a review cycle
- **So that** different review perspectives contribute appropriately to the overall evaluation

**US-100: Configure Form Weight Distribution**
- **As an** administrator
- **I want to** configure how weights are distributed across multiple review forms (e.g., self-review 20%, manager review 50%, peer review 30%)
- **So that** the overall evaluation reflects the importance of each review type

**US-101: Validate Form Weight Totals**
- **As an** administrator
- **I want to** ensure that form weights total 100% (or a specified value)
- **So that** the weighted calculation is mathematically correct

**US-102: Set Different Weights for Different Roles**
- **As an** administrator
- **I want to** set different form weight distributions for different employee roles or levels
- **So that** evaluation criteria reflect role-specific requirements

### 5.2 Question-Level Weightages

**US-103: Set Question Weight Within Form**
- **As an** administrator
- **I want to** assign weight values to individual questions within a review form
- **So that** certain questions contribute more to the form's overall score

**US-104: Set Section Weight Within Form**
- **As an** administrator
- **I want to** assign weight values to sections within a review form
- **So that** different competency areas are weighted appropriately

**US-105: Configure Question Weight Distribution**
- **As an** administrator
- **I want to** configure how weights are distributed across questions in a form
- **So that** the form score accurately reflects the importance of each question

**US-106: Auto-Normalize Question Weights**
- **As an** administrator
- **I want to** automatically normalize question weights so they total 100% within a section or form
- **So that** I don't have to manually calculate weight distributions

### 5.3 Weightage Calculation and Display

**US-107: View Weighted Review Score**
- **As a** manager or administrator
- **I want to** view the calculated weighted score for an employee's review
- **So that** I can see the overall performance rating based on all review components

**US-108: View Weight Breakdown**
- **As a** manager or administrator
- **I want to** view a breakdown showing how each form and question contributed to the final weighted score
- **So that** I can understand the calculation and verify accuracy

**US-109: Export Weight Configuration**
- **As an** administrator
- **I want to** export the weight configuration for review cycles and forms
- **So that** I can document and share the evaluation methodology

**US-110: Apply Weight Template**
- **As an** administrator
- **I want to** apply a saved weight template to a new review cycle or form
- **So that** I can reuse proven weight configurations

## SUMMARY

This document contains **244 comprehensive user stories** organized into 15 major modules:

1. **Review Cycles** (16 user stories) - Creation, management, monitoring, and templates
2. **Goals with Checklists and Assignment** (28 user stories) - Goal creation, checklists, assignment, progress tracking, and collaboration
3. **Review Forms with Types** (25 user stories) - Form creation, different review types, assignment, and completion
4. **Review Form Questions** (29 user stories) - Question creation, all question types, and configuration
5. **Weightages of Review Forms** (12 user stories) - Form-level and question-level weightages, calculations, and display
6. **Engagement Module** (24 user stories) - Survey creation, distribution, completion, analytics, and action planning
7. **Stats, Comparisons, and Reports** (36 user stories) - Statistics, comparisons, various report types, configuration, export, and advanced analytics
8. **Continuous Feedback** (8 user stories) - Real-time feedback, feedback templates, and feedback management
9. **Performance Notes** (10 user stories) - Note creation, one-on-one notes, tagging, and note management
10. **Recognition and Rewards** (8 user stories) - Recognition features, badges, and recognition analytics
11. **Approval Workflows** (9 user stories) - Review approval, goal approval, and multi-level approval processes
12. **Notifications and Communication** (11 user stories) - Notification settings, preferences, and various notification types
13. **User Management and Permissions** (11 user stories) - User roles, permissions, user management, and access control
14. **Review Visibility and Sharing** (9 user stories) - Review visibility settings, sharing, and review discussions
15. **System Settings and Configuration** (8 user stories) - Organization settings, integrations, and system configuration

All user stories follow the standard format: **As a [role], I want [feature], so that [benefit]**, and are structured to match Performyard's comprehensive performance management approach.
